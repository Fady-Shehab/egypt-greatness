
# عظمة وجلال مصر

> رحلة تفاعلية عبر سبعة آلاف عام من الحضارة الإنسانية

موقع ويب تفاعلي يستعرض عظمة مصر عبر ستة محاور رئيسية، مبني بـ Vanilla JS/HTML/CSS .

---

## محاور الموقع

- **التاريخ** — خط زمني تفاعلي من 3200 ق.م حتى اليوم
- **الآثار** — أهرامات الجيزة، أبو الهول، الكرنك، أبو سمبل
- **الثقافة** — اللغة، الموسيقى، السينما، الفنون، التراث
- **القوة الناعمة** — عدادات متحركة وبطاقات تفاعلية
- **الجغرافيا** — النيل، سيناء، قناة السويس، الصحراء البيضاء
- **المستقبل** — مشاريع مصر 2030 مع شرائط تقدم متحركة
